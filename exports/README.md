# Exports

`ghidra_scripts/ExportMatchData.java` writes here unless `EXPORT_DIR` in
`user_preferences.cfg` names another folder. Git ignores everything in this folder except
this file. [../docs/EXPORTING.md](../docs/EXPORTING.md) explains how to export a build.

```
exports/<label>.functions.csv
exports/<label>.data.csv
exports/<label>.meta.json
```
